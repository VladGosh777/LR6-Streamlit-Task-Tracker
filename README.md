# Трекер навчальних завдань студента

Streamlit-застосунок для ведення лабораторних і практичних робіт за предметами. У списку видно дедлайни, пріоритети та статуси; пошук працює за назвою й приміткою.

## Можливості

- три сторінки: перегляд завдань, додавання запису та відомості про автора;
- SQLite з таблицями `subjects` і `tasks`, пов’язаними зовнішнім ключем;
- пошук, фільтр за предметом, оновлення статусу й видалення завдань;
- графік кількості завдань і виконаних робіт за предметами;
- п’ять предметів і десять прикладів завдань додаються під час першого запуску.

## Локальний запуск

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

SQLite-файл `tasks.db` створюється поруч із `db.py`. У Streamlit Community Cloud локальні файли не підходять для постійного зберігання змін між перезапусками; тут вони використовуються для демонстрації лабораторної роботи.
